# 🌊 AlgaeSphere — Інтерактивний вебсайт «Цікаві факти про водорості» (Біологія, 7 клас)

Сучасний, візуально вражаючий та інтерактивний освітній вебпроєкт, присвячений дивовижному світу водоростей за шкільною програмою 7 класу України.

---

## ✨ Особливості проєкту

1. **Глибоководний атмосферний UI/UX**:
   - Градієнтні кольори океанічних глибин (`#020b18` до смарагдового та бірюзового).
   - Ефект матового скла (**Glassmorphism**) з неоновими акцентами для карток та навігації.
   - Промені підводного сонця та світлові ефекти.

2. **Живі інтерактивні бульбашки (Canvas + Web Audio API)**:
   - Фізична симуляція спливаючих бульбашок із відблисками світла, різним розміром і плавним погойдуванням.
   - **Інтерактивність:** на бульбашки можна клікати мишкою або тапом, щоб луснути їх із приємним звуковим ефектом «поп» (синтезований чистий звук без жодних зовнішніх аудіофайлів).
   - Лічильник луснутих бульбашок у кутку екрана.

3. **Науково точний контент (Біологія, 7 клас)**:
   - **Шпаргалка знань:** будова водоростей, відсутність органів, слань (талом), ризоїди, хроматофор.
   - **Світловий спектр занурення:** розподіл зелених, бурих та червоних водоростей за глибиною (0м -> 100м -> 200м+).
   - **8 інтерактивних карток фактів з фільтрами:**
     - 🌬️ Біосферні легені планети (70% кисню виробляє океанічний планктон).
     - 👁️ Хламідомонада зі світлочутливим вічком (стигмою) та джгутиками.
     - 🌲 Макроцистіс — 60-метрові підводні ліси з повітряними пухирцями.
     - 🍮 Агар-агар з багрянок для мармеладу, зефіру та лабораторій.
     - 🚀 Хлорела як космічна їжа та джерело кисню для космонавтів.
     - 🩺 Ламінарія (морська капуста) — чемпіон з вмісту йоду.
     - ✨ Біолюмінесценція (нічне сяйво ночесвітки).
     - 🌿 Харові водорості — предки всіх наземних рослин.

4. **Інтерактивна вікторина на 5 запитань**:
   - Миттєва анімація: зелене сяйво для правильної відповіді, червоне — для помилки.
   - Детальне наукове пояснення до кожного запитання.
   - Підрахунок балів у реальному часі.
   - Фінальний екран з вітальним салютом (конфеті) та званням («Володар Океану», «Глибоководний Дослідник» тощо).

## 🚀 Інструкція: Деплой на Cloudflare Pages

Cloudflare Pages надає безкоштовний, надшвидкий та безпечний світовий хостинг з SSL-сертифікатом.

### Спосіб 1. Швидке пряме завантаження (Direct Upload — 1 хвилина)
Найпростіший спосіб без використання Git чи термінала:

1. Зайдіть у панель [Cloudflare Dashboard](https://dash.cloudflare.com/) і увійдіть у свій акаунт.
2. У лівому меню оберіть **Compute (Workers & Pages)** ➡️ **Pages**.
3. Натисніть кнопку **Upload assets** (або *Create application* ➡️ вкладка *Pages* ➡️ *Upload assets*).
4. Введіть назву проєкту (наприклад, `algae-facts-7th-grade`).
5. Перетягніть папку `algae-facts-website` (або заархівований zip-файл із `index.html`) у вікно завантаження.
6. Натисніть **Deploy site**.
7. Менше ніж за 10 секунд ваш сайт отримає безкоштовне посилання виду `https://algae-facts-7th-grade.pages.dev` з активним HTTPS!

---

### Спосіб 2. Через GitHub (Автоматичний деплой при кожному коміті)
Якщо ви хочете зберігати історію змін у Git:

1. Створіть новий репозиторій на [GitHub](https://github.com/new) (наприклад, `algae-facts`).
2. Запустіть команди у папці проєкту:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Algae educational website"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЮЗЕРНЕЙМ/algae-facts.git
   git push -u origin main
   ```
3. У панелі Cloudflare Pages оберіть **Connect to Git**.
4. Виберіть ваш репозиторій `algae-facts`.
5. У налаштуваннях збірки (**Build settings**):
   - **Framework preset:** None
   - **Build command:** (залиште порожнім)
   - **Build output directory:** (залиште `/` або порожнім)
6. Натисніть **Save and Deploy**. Тепер сайт оновлюватиметься автоматично при кожному `git push`!

---

### Спосіб 3. Через термінал (Cloudflare Wrangler CLI)
```bash
# Встановлення wrangler (якщо ще не встановлено)
npm install -g wrangler

# Авторизація в Cloudflare
wrangler login

# Публікація проєкту
wrangler pages deploy C:\Users\vikto\.gemini\antigravity\scratch\algae-facts-website --project-name algae-facts
```

## 🛠️ Стек технологій
- **HTML5:** Семантична, доступна структура.
- **Tailwind CSS (CDN):** Адаптивна стилізація, кольорові палітри океану та ефекти скла.
- **Vanilla JavaScript (ES6+):** Фізика частинок Canvas, Web Audio API, логіка тесту, фільтрація карток.
- **Lucide Icons:** Сучасні векторні іконки.
- **Canvas-Confetti:** Ефект свята при відмінному проходженні тесту.
