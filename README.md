# Світ Водоростей • Таємниці Океанських Глибин

Сучасний, візуальний та інтерактивний освітній вебресурс про водорості, будову морської капусти (ламінарії), родини та роль водоростей у природі й житті людини.

---

## Особливості проєкту

1. **Атмосферний океанічний UI/UX**:
   - Палітра світлих і глибоких аквамаринових, смарагдових та бірюзових тонів.
   - Ефект кришталевого скла (**Glassmorphism**) з неоновими підводними відблисками.
   - Смілива сучасна типографіка (`Unbounded` та `Plus Jakarta Sans`) з бездоганною кирилицею.

2. **Інтерактивна анатомія водоростей (Ламінарія, Ульва, Порфіра)**:
   - Детальний інтерактивний розбір будови морської капусти (слань/пластинка, стовбурець, ризоїди).
   - Візуальні моделі та науковий опис клітинних пігментів.

3. **Світловий спектр та глибиномір (0 – 200+ м)**:
   - Інтерактивна шкала проникнення сонячного світла в океані.
   - Розподіл 3 головних родин: Зелені (хлорофіл), Бурі (фукоксантин), Червоні (фікоеритрин).

4. **Водорості в щоденному житті**:
   - Інтерактивні картки про альгінати, агар-агар, норі та екстракти водоростей (морозиво, мармелад, суші, зубна паста).
   - 100% чиста векторна графіка (SVG), без шрифтових емодзі та дефектів відображення на будь-яких пристроях.

5. **Руйнівники міфів та інтерактивний бліц-тест**:
   - Наукові відповіді на поширені помилки.
   - Швидкий бліц-тест із миттєвими підказками, звуковим супроводом (Web Audio API) та перемішуванням запитань.

6. **Фірмовий Favicon та прев'ю в соцмережах (Open Graph)**:
   - Векторний `favicon.svg` для вкладки браузера.
   - Картка високої роздільної здатності (1200×630 px) для Telegram, Viber, WhatsApp та соцмереж.

---
